BUBU & DUDU STICKERS
====================
Drop the files in this folder using these exact names. .gif and .webp both
work - just make the filename here match the one the page asks for. Anything
that isn't here yet shows up on the site as a small dashed box labelled with
the filename it's waiting for, so you can always see what's still missing.

"ok" means the file is already in this folder.


LOADING SCREEN  (index.php only, once per visit)
     bubu-wait.gif            Bubu sitting alone, waiting
     dudu-arrive.gif          Dudu walking in
     hug.gif                  the two of them hugging  (reused in 3 places)

  ok bubu-wave.webp           waving hello
  ok dudu-not-wave.webp       the other one, pointedly not waving

Square-ish files with transparent backgrounds look best - anything with a
solid white background shows as a visible box on these dark pages.
Sizing is handled entirely in CSS, so don't worry about pixel dimensions.
